# 合成验证场景

以下示例不依赖真实站点或账号。用例可分别提交给 Coding Agent；评估自动选择时不要在提示中点名 Skill。先记录实际加载的 Skill 和参考文件，再比较它给出的下一步。对比版本时保持提示及可用工具一致。

| 输入 | 预期可观察行为 |
| --- | --- |
| 提供已验证的新搜索框定位，要求只修复旧定位 | 定点修改与验证，不展开全站探索 |
| 为陌生公开目录开发分页采集器 | 明确字段来源、记录 ID、翻页或游标终点，小样本验证后再放量 |
| 官方端点已获准，覆盖所需字段 | 先验证 API 契约，无需先搭 UI 路线 |
| 现有 UI 路线满足吞吐和可靠性指标，询问是否迁移 | 复用现有路径，不追查未公开接口 |
| 页面改版后只有详情 iframe 步骤失效 | 补采详情的帧身份、作用域和状态，保留未变化路径 |
| 点击提交后超时，结果未知 | 查询对应业务对象的远端状态，禁止换执行器或盲重试 |
| 关键保存按钮所在帧不可观察 | 标记阻塞，说明所需证据，不编造定位或执行替代点击 |
| 只要求截取本地网页一张图 | 用已授权浏览器工具操作，无完整开发流程 |

需要验证工具操作本身时，使用本地 fixture 或获准测试环境；离线决策通过不能替代客户端自动触发或真实浏览器验证。
